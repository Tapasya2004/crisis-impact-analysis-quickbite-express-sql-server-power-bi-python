# SQL Analysis

SQL Server was used as the analytical data layer for the QuickBite project.

The analysis relied on relational joins, aggregations, CTE-style transformations, ranking/window logic, KPI calculations, and derived analytical tables to support Power BI reporting.

The exact original `.sql` source files were not present in the supplied project artifacts used to assemble this repository. They should be added here rather than recreating them under false filenames.
